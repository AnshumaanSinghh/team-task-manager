# TaskFlow frontend

React 19 + Vite + Tailwind CSS 4. See the [main README](../README.md) for features and setup.

```bash
npm install            # no .env needed: /api is proxied to http://localhost:5000
npm run dev            # http://localhost:3000
npm run lint
npm run build
```

Design tokens (black, green and white, dark and light themes), the 3D button styles and the tilt cards live in `src/index.css`.
