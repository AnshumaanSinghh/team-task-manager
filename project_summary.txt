TASKFLOW: PROJECT SUMMARY & DIFFERENTIATORS (v3)

1. CORE PLATFORM
--------------------------------------------------
- Full stack: React 19 (Vite, Tailwind CSS 4) frontend + Node.js / Express 5 API + MongoDB.
- JWT authentication, bcrypt hashing, rate-limited sign in and sign up.
- Role-based access control enforced on the server for every project, task,
  comment, activity, pulse, playback and standup endpoint (members only see
  projects they belong to; only admins edit task details).
- Four-column Kanban (To Do, In Progress, In Review, Completed) with drag and
  drop ordering that persists, plus a sortable List view and a month Calendar.
- Dashboard: team velocity (14 days), completion ring, status and priority
  breakdown, my next deadlines, shipping streak, focus minutes, activity feed.

2. WHAT MAKES IT UNIQUE
--------------------------------------------------
A. Blockers and dependencies: tasks can wait on other tasks. The API refuses to
   complete a blocked task and rejects dependency cycles.
B. WIP limits per column with a striped over-limit warning.
C. Focus Mode: 25/50 minute sessions with a full-screen timer; time is logged
   to the task and shown on the Team page as live presence.
D. Team workload: open work, overdue, story points, weekly output, kudos and
   focus minutes per person, with overload detection.
E. Async standup generator: Done / Doing / Blockers per member, copied as
   Markdown.
F. Quick Add: "Design pricing page by Friday @riya #design 3pts urgent" becomes a
   task with owner, timezone-correct due date, tag, estimate and priority.
   Built-in parser works with no AI keys; Groq / Gemini / OpenRouter refine it.
G. AI Planner: goal -> reviewable plan (tasks, estimates, checklists, dates)
   before anything is created; built-in playbooks as fallback.
H. @mentions with autocomplete and a notification inbox (assignments, mentions,
   comments, status changes, kudos) that deep-links to the task.
I. Kudos on completed work, decision log, project pulse (health score with
   burnout warnings), ghost playback with scrubber and speed control.
J. Revocable, privacy-safe public share links (no emails, comments or time logs).
K. Command palette (Ctrl/Cmd K) with task search, and keyboard shortcuts.

3. DESIGN
--------------------------------------------------
Black, green and white design system with dark and light themes, 3D press
buttons, tilt-on-hover cards, page transitions, spring modals, animated counters
and a circular theme reveal (View Transitions API). Respects reduced motion.

4. QUALITY
--------------------------------------------------
- Backend unit tests (parser, mentions, pulse, standup, planner) and an
  end-to-end API test against a real MongoDB (node:test).
- Frontend lint clean (ESLint + React Hooks rules), production build verified.
- Demo seed script: npm run seed.
